# Changelog

Gerado por `scripts/release.ts` (issue #531) a partir de `git log
--first-parent --merges` — sem `gh`/`gh api`, sem rede. Cada entrada é o
título da PR mergeada (o corpo do merge commit), agrupada pelo tipo do
conventional commit no título; `### Other` cobre o que não casa nenhum tipo
conhecido.

A entrada `[0.0.11]` abaixo é retroativa: reúne todo o histórico deste
repositório até aqui, porque nunca houve uma tag `v*` (`git tag` vazio antes
desta PR). Antes de cortar a próxima versão (`release/0.0.12`), o owner
precisa criar a tag `v0.0.11` sobre o merge commit desta PR — sem ela,
`npm run release` recontaria o mesmo histórico inteiro em `[0.0.12]`
(`lastReleaseTag` só filtra por `git tag --list 'v*'`; ver `docs/release.md`).
